# Project Name: Employee Database Project
## Project Description
This project is a simple, easy-to-use Employee Database program designed in Java with SQL database functions. With this program, you can add, edit, delete and display any
Employees alongside their weekly payout and the conditions of their pay. This includes whether they are paid hourly, are commissioned or get paid salary. It has an active storage functionality so booting up the program will not overwrite or delete any employees already created by the program.
## Project Tasks
- **Task 1: Set up the development environment**
- Install necessary software and tools (VSCode & SQLite)
- Configure Git and GitHub repository
- **Task 2: Plan the project**
- Scope is to create 3 Employee types to be extended from one single employee class.
- Each employee type must have an associated table and have information able to be called on, edited and deleted.
- **Task 3: Implement core features**
- Develop the main functionalities of the application, including a switch case menu, the Employee, Hourly, Salary and Commission classes with a CalculatePay interface to assist in calculating and displaying the proper wages being made by each employee. A Wage Calculator class further assists with this.
- Create the SQLDatabase components, including the connector and database tables themselves.
- A Database Manipulator class to allow for the editing or deletion of an employee of the user's choosing.
- **Task 4: Test the application**
- Perform unit and integration testing
- Debug and fix issues
- **Task 5: Document the project**
- Create a comprehensive README file
- Write user and developer documentation (that is this)
## Project Skills Learned
- SQL integration with Java programs, tying together objects created with a database to populate tables.
- Composition, Inheritance and other OOP concepts in Java Programming to create objects and help assign properties to each object to store information.
- More effective runtime practices, learning to condense code into other objects, functions and classes to allow for cleaner code
## Language Used
- **Java** as the main program
- **SQLite** as the framework for the database to store the data in.
